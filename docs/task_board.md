# 项目任务看板

## 使用说明
本看板按敏捷协作方式组织，按“功能是否形成可交付能力”来移动任务状态。

推荐使用状态列：

- `Backlog`
- `Ready`
- `Doing`
- `Review`
- `Done`

---

## Backlog

- 完成 `GLFW + GLAD + ImGui` 基础工程搭建
- 建立 `Shader / Texture / Camera / Model` 基础类
- 接入 `OBJ` 模型加载
- 接入 `PNG/JPG` 纹理加载
- 完成第一个带纹理模型渲染
- 搭建室内主场景结构
- 导入不少于 `5` 个独立模型
- 实现方向光
- 实现点光源
- 实现聚光灯
- 实现第一人称相机漫游
- 实现 `ImGui` 参数调节面板
- 实现至少一种阴影映射
- 加入一个增强项
- 完成演示脚本整理
- 完成答辩材料整理

## Ready

- 明确场景主题与风格
- 统一建模规范、坐标轴规范、尺寸单位
- 确定资源目录结构
- 确定模型命名规范与贴图命名规范
- 明确最小可验收目标

## Doing

- 模型路径与贴图路径联调
- 材质参数绑定与默认值调整
- 相机移动速度、鼠标灵敏度、俯仰角限制微调
- 光照参数初始值调优
- 阴影偏移与深度图分辨率调优
- 场景中模型摆放与整体氛围统一

## Review

- 检查模型数量是否达到要求
- 检查所有模型是否具备合理 UV 与纹理显示
- 检查三类光源是否均可演示
- 检查阴影是否能正确投射到环境和其他物体表面
- 检查第一人称漫游是否稳定
- 检查 ImGui 面板是否支持实时调参
- 检查增强项是否能稳定演示

## Done

- 技术选型确定为 `OpenGL Core Profile + C++ + GLFW/GLAD + ImGui`
- 协作方式确定为两人分工开发
- 成员 A 负责程序与渲染
- 成员 B 负责模型与贴图资源
- 资源格式确定为 `OBJ + PNG/JPG`
- 推进方式确定为“先最小闭环，再逐步增强”

---

## 建议拆分方式

### 成员 A：程序侧任务
- 工程与依赖配置
- 渲染框架搭建
- 相机与输入系统
- 光照系统
- 阴影系统
- GUI 面板
- 最终整合与演示

### 成员 B：资源侧任务
- 场景设定与参考图整理
- 主体空间建模
- 道具与装饰建模
- UV 展开
- PNG 贴图制作
- 模型导出与资源归档
