# 图形学课程实验报告

## 1. 实验目的

本次实验旨在使用 `OpenGL Core Profile + C++ + GLFW/GLAD + ImGui` 自主实现一个室内或半室内三维场景，不依赖 Unity、Unreal Engine、Godot 等成熟游戏引擎。通过本实验，需要综合完成模型加载、纹理材质、实时光照、阴影映射、相机漫游、GUI 调参与动态效果等内容，提升对图形渲染管线与场景系统设计的理解。

## 2. 场景构思与技术方案

### 2.1 场景构思
- 场景定位为具有封闭空间感的室内场景，便于突出光照与阴影效果。
- 场景构成包括主模型、地面、障碍物、灯光、粒子发射器及动态元素。
- 色彩搭配以环境主色、点光源局部色和聚光灯强调色形成层次。
- 光影设定采用方向光作为主光源，点光源作为局部补光，聚光灯绑定相机用于强调交互感。

### 2.2 技术方案
- 图形 API：`OpenGL Core Profile`
- 开发语言：`C++`
- 窗口与输入：`GLFW`
- OpenGL 函数加载：`GLAD`
- 实时调试界面：`ImGui`
- 数学库：`GLM`
- 图片解码：`stb_image`

### 2.3 技术架构说明
- 资源层：
  - Shader 文件读取
  - OBJ 模型读取
  - MTL 材质与 `map_Kd` 纹理路径解析
  - 图片纹理解码与 OpenGL 上传
- 场景层：
  - 外部配置文件驱动模型、光照、碰撞、粒子、阴影参数
  - 支持多个模型实例、多个障碍物、多个点光源、多个粒子发射器
- 渲染层：
  - 主渲染 pass：模型、地面、光照与阴影采样
  - 深度渲染 pass：方向光阴影映射
  - 粒子渲染 pass：三维空间粒子点集
- 交互层：
  - 第一人称相机
  - 鼠标捕获与释放切换
  - ImGui 选项卡式调试界面

## 3. 实验内容

### 3.1 基础工程搭建
- 使用 CMake 建立工程
- 集成 GLFW、GLAD、GLM、ImGui、stb_image
- 配置 UTF-8 文本规范与项目目录结构

### 3.2 场景资源系统实现
- 实现 Shader 文件读取
- 实现 OBJ 模型解析
- 实现 MTL 材质读取
- 实现纹理解码与上传

### 3.3 场景与交互实现
- 实现第一人称相机
- 实现 WASD、Q/E、Shift 加速与鼠标视角控制
- 实现鼠标捕获/释放切换
- 实现 ImGui 参数控制面板

### 3.4 光照与阴影实现
- 实现方向光
- 实现点光源
- 实现聚光灯
- 实现方向光阴影映射
- 实现阴影开关与偏移调节

### 3.5 场景增强效果
- 实现碰撞检测
- 实现刚体动画
- 实现粒子系统
- 实现配置驱动的多模型、多障碍物、多点光源、多粒子发射器
